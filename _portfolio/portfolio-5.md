## Resume Screening System

An **AI-powered resume screening system** that helps automate the recruitment process by analyzing resumes and identifying suitable candidates.

### Key Features

- Resume text extraction and preprocessing
- Candidate classification
- Resume–job matching
- Automated candidate screening
- High-accuracy predictions

### Technologies

**Python · Machine Learning · NLP · Scikit-learn · TF-IDF · Streamlit**

This project demonstrates practical experience in applying **Machine Learning and NLP to real-world recruitment automation**.
