## NeuroChat AI

A **neural network-based NLP and Deep learning chatbot** built from scratch using **PyTorch and NLTK**, with an end-to-end pipeline for text preprocessing, intent classification, and response generation.

### Key Features

- Text tokenization and stemming
- Bag-of-Words feature extraction
- Neural network-based intent classification
- Automated response selection
- Flask-based deployment

### Model Architecture

**Bag of Words → Linear → ReLU → Linear → ReLU → Linear → Intent**

### Technologies

**Python · PyTorch · NLTK · NLP · Deep Learning · Neural Networks · Flask**

This project demonstrates practical understanding of **core NLP and Deep Learning concepts**, building a conversational AI system without relying on pre-built chatbot APIs.
