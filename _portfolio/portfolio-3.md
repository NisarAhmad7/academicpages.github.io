## CodePilot AI

A **multi-agent AI software engineering system** built with **LangGraph and LLMs** that transforms natural-language application requirements into structured and generated software projects.

### Key Features

- Multi-agent planning and execution
- Automated project architecture
- Task decomposition
- Iterative code generation
- Tool-based file operations
- Stateful workflow management
- Secure project file management

### Architecture

**Planner → Architect → Coder → Generated Project**

### Technologies

**Python · LangGraph · LangChain · Groq · LLMs · Pydantic · Agentic AI · Tool Calling**

This project demonstrates practical experience in building **agentic AI systems that automate software development through planning, reasoning, tool usage, and iterative execution**.
