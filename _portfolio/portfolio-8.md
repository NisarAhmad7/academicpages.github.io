## SQL Query Generator

An **AI-powered SQL query generation system** that converts natural-language user requests into **SQL queries**, enabling users to interact with and retrieve information from databases without manually writing SQL.

### Key Features

* Natural-language to SQL query generation
* Automated SQL query construction
* Database interaction and query execution
* Structured retrieval of database information
* Support for data analysis through natural-language requests
* LLM-powered query generation workflow

### Technologies

**Python · SQL · LLMs · Prompt Engineering · SQLite · Natural Language Processing · Streamlit**

This project demonstrates practical experience in building **LLM-powered database applications** that simplify SQL interaction and enable users to work with databases through natural language.
